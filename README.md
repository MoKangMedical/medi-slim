## 🎯 一句话定位

**MediSlim = AI驱动的消费医疗平台**，用技术重构「评估→推荐→预约→术后」全链路，让医美消费更透明、更安全、更高效。

## 🚀 核心功能

| # | 功能 | 说明 |
|---|------|------|
| 1 | 🤖 **智能推荐** | 基于AI的医美项目推荐，结合用户体质、预算、需求精准匹配 |
| 2 | 🏥 **机构认证** | 医美机构资质审核，确保合作方合规持证 |
| 3 | 💰 **价格透明** | 项目价格横向对比，消除信息不对称 |
| 4 | ⭐ **用户评价** | 真实用户反馈和效果展示，辅助决策 |
| 5 | 📅 **在线预约** | 智能排班和一键预约，减少等待 |
| 6 | 🔬 **术后管理** | AI随访和效果追踪，提升满意度 |
| 7 | 👨‍⚕️ **医生IP** | 医生个人品牌展示，建立信任连接 |
| 8 | 📋 **合规管理** | 医疗合规自动化审查，降低法律风险 |

## 💰 商业模式

### 收入公式

```
月收入 = 自然流量 × 转化率 × 客单价 × (1 + 复购率 × 购买次数)
```

### 三大收入来源

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/MoKangMedical/medi-slim.git
cd medi-slim
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动应用

```bash
# 主应用
streamlit run app.py --server.port 8090

# 获客落地页
streamlit run landing.py --server.port 8091

# AI推荐引擎 demo
streamlit run src/app.py --server.port 8094
```

### 4. 企业健康管理

```bash
cd enterprise-b2b
python3 app.py
```
