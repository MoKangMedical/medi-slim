# MediSlim 商业模式详解

> **核心理念**：只做流量层，医疗合规全外包。AI驱动全链路，从获客到复购。

---

## 一、商业定位

### 红杉论点

> 下一代万亿美元公司是伪装成服务公司的软件公司。从卖工具到卖结果。

MediSlim 不卖 SaaS，卖**健康管理结果**（评估→方案→效果→复购）。AI驱动全链路，边际成本趋零。

### 轻资产模型

```
MediSlim (流量+AI)        合作伙伴 (全外包)
┌──────────────────┐     ┌──────────────────┐
│ 品牌 & 流量       │ ←→ │ 互联网医院        │
│ AI健康助手        │ ←→ │ 合规药房          │
│ 智能营销          │ ←→ │ 物流配送          │
│ 数据分析          │ ←→ │ 客服(人工兜底)    │
└──────────────────┘     └──────────────────┘
       ↑
  90% AI + 10% 外包
```

## 三、三大收入来源

### 1. 交易佣金（60%）

每笔通过平台成交的医美项目，收取 **5-15%** 佣金。

| 项目类型 | 客单价 | 佣金率 | 单笔佣金 |
|---------|--------|--------|---------|
| 注射类（玻尿酸/肉毒素） | ¥3,000 | 10% | ¥300 |
| 光电类（热玛吉/光子） | ¥15,000 | 8% | ¥1,200 |
| 手术类（双眼皮/隆鼻） | ¥20,000 | 5% | ¥1,000 |

### 2. B2B 企业健康管理（25%）

企业 HR 付费，员工免费使用。

| 版本 | 人数 | 单价/人/月 | 年费（100人） |
|------|------|-----------|-------------|
| 小微版 | ≤100人 | ¥30 | ¥36,000 |
| 标准版 | 101-500人 | ¥25 | ¥30,000 |
| 企业版 | 500+人 | ¥20 | ¥24,000 |

**ROI 8.2x**：员工健康 → 减少病假 → 提升效率

### 3. 营销服务（15%）

为医美机构提供品牌推广和精准获客服务。

- 小红书/抖音/朋友圈内容生成
- 精准人群投放
- 品牌专区展示

## 六、竞争壁垒

1. **Harness 理论**：环境设计比模型本身更重要，MediSlim 的 Harness 是私有的
2. **数据飞轮**：用户行为数据 → AI 更精准 → 更高转化
3. **合规护城河**：医疗合规自动化审查，后来者难以复制
4. **医生 IP 矩阵**：绑定优质医生资源，形成供给端壁垒
