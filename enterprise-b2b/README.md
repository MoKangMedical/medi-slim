# MediSlim 企业健康管理MVP

> **越狱思维验证 #2**：员工是用户，企业HR是付费方

## 商业模式

```
Parakeet Chat:  囚犯(用户) → 家属付费($15/月)
MediSlim:       员工(用户) → 企业HR付费(¥25/人/月)
```

**核心逻辑**：企业每年每员工平均医疗支出¥3000-5000。健康管理提升30%→节省¥1000+/人/年。平台费¥300/人/年 = ROI 3x+。

## 越狱思维五大映射

| 原则 | Parakeet Chat | MediSlim 企业版 |
|------|--------------|----------------|
| 分离支付 | 囚犯用，家属付 | 员工用，企业HR付 |
| 管道寄生 | Corrlinks邮件 | 企业微信/钉钉 |
| 无界面 | 纯邮件 | 企业微信对话 |
| 封闭增长 | 监狱口碑 | 企业内/行业内口碑 |
| 情感定价 | $15/月(连接亲人) | ¥25/人/月(员工关怀) |

## 快速启动

```bash
cd /root/medi-slim/enterprise-b2b
pip install flask
python app.py
# HR后台: http://localhost:5002/admin
# 员工入口: http://localhost:5002/employee
```

## 功能

### HR管理后台 (/admin)
- 📊 仪表盘：员工数、健康分、覆盖率、预估节省
- 📈 部门健康对比图表
- 👥 员工健康排行
- 💰 ROI计算器

### 员工健康入口 (/employee)
- 📝 每日健康打卡（睡眠/运动/饮水/心情）
- 🧬 中医体质快速测试
- 🤖 AI健康问答
- 📋 个性化健康方案推荐
